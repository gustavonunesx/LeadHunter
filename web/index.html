Controle de consumo

Os limites contam tentativas, inclusive falhas. Chamadas pagas não se repetem automaticamente. Tokens Jev e custos informados pela busca são registrados separadamente.

O que esta versão valida

A coleta real depende das suas credenciais e do acesso aos provedores. A demonstração usa dados fictícios. Jev está integrado à classificação; a navegação autônoma pelo Maps é uma etapa posterior do plano.
